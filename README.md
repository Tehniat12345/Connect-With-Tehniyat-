## 📄 Website Structure
This is a multi-page website consisting of the following sections:
* **Home (index.html):** A clean landing page with a professional introduction and primary call-to-actions.
* **About Me (about.html):** Detailed insights into my professional journey, expertise, and design philosophy.
* **Services (services.html):** A showcase of the high-quality services I offer, including Web Development, UI/UX Design, and Graphic Solutions.
* **Portfolio (portfolio.html):** A curated gallery of my best works across various industries.
* **Contact (contact.html):** An interactive section for clients and collaborators to reach out easily.
* **Mini Portfolio (one page.html):** A stylish, modern, and dark-themed single-page version of my profile for quick viewing.

## 🛠️ Technical Expertise
* **Front-End:** HTML5, CSS3 (Flexbox & Grid).
* **Design Framework:** Custom CSS variables for consistent branding (Teal & Dark Green theme).
* **Typography:** Google Fonts (Poppins, Bodoni Moda, Montserrat).
* **Interactivity:** CSS3 animations, hover effects, and responsive navigation.
* **Icons:** FontAwesome integration for social media and UI elements.

## ✨ Key Features
* **Consistent Branding:** A professional color palette (Teal/Dark Green) used throughout the multi-page structure.
* **Responsive Design:** Optimized for mobile, tablet, and desktop viewing.
* **Social Integration:** Direct links to my Fiverr, LinkedIn, Instagram, and TikTok profiles.
* **Modern Aesthetics:** Use of glassmorphism effects and editorial-style layouts.
